# Image Prompt Generator Template

Produce ONE image-generation prompt to accompany today's chosen post.

## Style rules (consistent visual brand)
- Clean, modern technical illustration or realistic render — never stock-photo clichés (no handshake, no lightbulb, no generic EV plugged in at sunset).
- Palette: deep navy, electric teal, white, with one amber accent.
- Composition: subject right-of-center, negative space left for potential text overlay.
- No text, no logos, no watermarks in the image itself.

## Output
- `prompt:` a detailed English prompt ready for the image generation tool (specify lighting, perspective, mood).
- `ratio:` 3:2 (feed post) or 1:1 (carousel cover).
- `alt_text:` one accessibility sentence.
